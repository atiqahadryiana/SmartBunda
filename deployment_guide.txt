# SmartBunda Deployment Guide

## APK Deployment

### Location of Generated APK:
File: C:\Users\adryi\Desktop\FYP\Smartbunda\build\app\outputs\flutter-apk\app-release.apk
Size: 71.8MB

### Steps to Deploy APK:

1. **Local Testing:**
   - Connect Android device via USB
   - Enable Developer Options and USB Debugging
   - Install APK: `adb install app-release.apk`

2. **Google Play Store Deployment:**
   - Create Google Play Developer account
   - Prepare store listing assets (screenshots, descriptions)
   - Upload APK to Google Play Console
   - Complete content rating and pricing
   - Submit for review

3. **Direct Distribution:**
   - Host APK on website for direct download
   - Users need to enable "Install from Unknown Sources"
   - Consider using services like Firebase App Distribution for beta testing

## Web Deployment

### Location of Generated Web Build:
Directory: C:\Users\adryi\Desktop\FYP\Smartbunda\build\web

### Steps to Deploy Web Application:

1. **Firebase Hosting (Recommended):**
   ```bash
   # Install Firebase CLI
   npm install -g firebase-tools
   
   # Login to Firebase
   firebase login
   
   # Initialize Firebase project
   firebase init hosting
   
   # Deploy to Firebase
   firebase deploy
   ```

2. **Manual Web Hosting:**
   - Upload entire contents of build\web directory to web server
   - Ensure proper MIME types are configured
   - Configure web server for single-page application routing

3. **GitHub Pages Deployment:**
   - Create gh-pages branch
   - Push build\web contents to gh-pages branch
   - Configure GitHub Pages in repository settings
